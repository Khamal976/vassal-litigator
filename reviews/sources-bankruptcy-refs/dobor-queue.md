**Составлено 2026-07-31.** Цель файла — чтобы следующий заход не искал реквизиты заново: поиск по корпусу стоит дорого (выдача 70–90 КБ на запрос), а сопоставление номер → `case_id` уже сделано.

## Как добирать

- **Акты и статьи (КонсультантПлюс)** — `python fetch_source.py <URL> <файл> --title "..." --reason "..."`. Канал перемежающийся: свежий процесс проходит с первой попытки, после ~50 запросов подряд сервер отказывает надолго. Длинные акты добытчик собирает по разделам сам.
- **Определения (корпус MCP)** — `vasrf_search_practice` для поиска, `vasrf_get_case_details(case_id)` для текста. **Карточка приходит целиком в контекст (15–20 КБ)** — по одной за раз, сразу записывать выдержки в `sources0/` по конвенции `opr-*.txt` (выдержки, а не полный текст).

## Правовая находка захода (проверена по первоисточнику)

**Расхождение Д-9 инвентаризации разрешается по дате, а не в чью-то пользу.** Определение 305-ЭС23-22266 (март 2024) прямо говорит: «к корпоративным убыткам как к активу самого должника (его акционеров) этот механизм [ст. 61.17] не может быть применим». Пункт 69(1) Пленума № 53, **введённый 23.12.2025**, говорит обратное — распоряжение требованием возможно «с учетом положений статьи 61.17». Действует более поздний Пленум; определение цитировать только с оговоркой о дате. Прежняя формулировка справочника по субсидиарке («неприменим») была верна на момент написания и **устарела**, а не ошибочна — это меняет тон правки: не исправление ошибки, а актуализация.
