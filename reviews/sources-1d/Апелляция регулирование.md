# Какими нормами и судебной практикой (пленумы, обзоры) регламентируется производство в апелляционной инстанции  АПК и ГПК? не выдумывай содержание норм.

У меня достаточно информации для подготовки полного структурированного ответа. Теперь составлю ответ.

## Апелляционное производство в АПК РФ и ГПК РФ: нормы и судебная практика


***

## I. НОРМАТИВНАЯ БАЗА

### А. АПК РФ — Глава 34 (ст. 257–272.1)

Производство в арбитражном суде апелляционной инстанции регулируется **Главой 34 АПК РФ**, включающей следующие ключевые статьи:[^1_1]


| Статья АПК РФ | Предмет регулирования |
| :-- | :-- |
| **Ст. 257** | Право апелляционного обжалования; порядок подачи жалобы |
| **Ст. 258** | Арбитражный суд апелляционной инстанции |
| **Ст. 259** | Срок подачи апелляционной жалобы (1 месяц; 6 мес. — пресекательный для восстановления) |
| **Ст. 260** | Форма и содержание апелляционной жалобы |
| **Ст. 261** | Принятие апелляционной жалобы к производству |
| **Ст. 262** | Отзыв на апелляционную жалобу |
| **Ст. 263** | Оставление апелляционной жалобы без движения |
| **Ст. 264** | Возвращение апелляционной жалобы |
| **Ст. 265** | Прекращение производства по апелляционной жалобе |
| **Ст. 265.1** | Приостановление исполнения судебных актов апелляционным судом |
| **Ст. 266** | Порядок рассмотрения дела (по правилам 1-й инстанции с особенностями) |
| **Ст. 267** | Срок рассмотрения апелляционной жалобы (2 месяца) |
| **Ст. 268** | Пределы рассмотрения дела в апелляции |
| **Ст. 269** | Полномочия арбитражного суда апелляционной инстанции |
| **Ст. 270** | Основания для изменения или отмены решения |
| **Ст. 271** | Постановление арбитражного суда апелляционной инстанции |
| **Ст. 272** | Апелляционные жалобы на определения |
| **Ст. 272.1** | Апелляционные жалобы на решения по делам упрощённого производства |

Статья 266 АПК РФ прямо устанавливает, что арбитражный суд апелляционной инстанции рассматривает дело в судебном заседании по правилам рассмотрения дела судом первой инстанции с особенностями, предусмотренными главой 34, при этом в апелляции не применяются правила о соединении требований, изменении предмета или основания иска, изменении размера требований, предъявлении встречного иска, замене ненадлежащего ответчика, привлечении третьих лиц.[^1_2]

### Б. ГПК РФ — Глава 39 (ст. 320–335)

Апелляционное производство в судах общей юрисдикции регулируется **Главой 39 ГПК РФ**:[^1_3]


| Статья ГПК РФ | Предмет регулирования |
| :-- | :-- |
| **Ст. 320** | Право апелляционного обжалования |
| **Ст. 320.1** | Суды, рассматривающие апелляционные жалобы, представления |
| **Ст. 321** | Порядок и срок подачи апелляционной жалобы (1 месяц) |
| **Ст. 322** | Содержание апелляционной жалобы |
| **Ст. 323** | Оставление апелляционной жалобы без движения |
| **Ст. 324** | Возвращение апелляционной жалобы |
| **Ст. 325** | Действия суда первой инстанции после получения жалобы |
| **Ст. 326** | Отказ от апелляционной жалобы |
| **Ст. 326.1** | Отказ истца от иска, признание иска, мировое соглашение в апелляции |
| **Ст. 327** | Порядок рассмотрения дела в апелляции |
| **Ст. 327.1** | Пределы рассмотрения дела в апелляции |
| **Ст. 327.2** | Сроки рассмотрения дела в апелляционной инстанции |
| **Ст. 328** | Полномочия суда апелляционной инстанции |
| **Ст. 329** | Постановление суда апелляционной инстанции |
| **Ст. 330** | Основания для отмены или изменения решения суда в апелляционном порядке |
| **Ст. 330.1** | Порядок рассмотрения жалоб, поступивших после рассмотрения дела |
| **Ст. 331** | Обжалование определений суда первой инстанции |
| **Ст. 332** | Срок подачи частной жалобы |
| **Ст. 333** | Порядок подачи и рассмотрения частной жалобы |
| **Ст. 334** | Полномочия суда при рассмотрении частной жалобы |
| **Ст. 335** | Законная сила определения суда апелляционной инстанции |
| **Ст. 335.1** | Особенности рассмотрения апелляционной жалобы на решение по делу упрощённого производства |

Статья 327.1 ГПК РФ закрепляет принцип **неполной апелляции**: суд рассматривает дело в пределах доводов, изложенных в апелляционных жалобе, представлении и возражениях относительно жалобы.[^1_4]

## II. КЛЮЧЕВЫЕ ПОСТАНОВЛЕНИЯ ПЛЕНУМА ВЕРХОВНОГО СУДА РФ

### А. По АПК РФ

**Постановление Пленума ВС РФ от 30.06.2020 № 12** «О применении Арбитражного процессуального кодекса Российской Федерации при рассмотрении дел в арбитражном суде апелляционной инстанции»  — является основным действующим разъяснением. Заменило утратившее силу Постановление Пленума ВАС РФ от 28.05.2009 № 36.[^1_5][^1_6]

Структура и ключевые позиции постановления:[^1_7]

**Раздел 1 — Общие положения. Субъекты и объекты обжалования (п. 1–7):**

- Правом апелляционного обжалования обладают лица, участвующие в деле, иные лица по ст. 42 АПК РФ (если судебный акт принят об их правах и обязанностях), правопреемники, эксперты/специалисты/свидетели/переводчики в части выплаты вознаграждения, прокурор по делам ч. 1 ст. 52 АПК РФ даже без участия в 1-й инстанции, бизнес-омбудсмены — только при участии в 1-й инстанции[^1_8]
- Судебные приказы, определения по третейским делам, по иностранным решениям — обжалуются исключительно в кассационном порядке (ч. 11 ст. 229.5, ч. 5 ст. 234, ч. 5 ст. 240, ч. 3 ст. 245, ч. 14 ст. 245.1 АПК РФ); решения СИП вступают в силу немедленно и обжалуются в президиум СИП[^1_7]
- Частная определение по ст. 188.1 АПК РФ может быть обжаловано в течение 10 дней[^1_9]
- Апелляционная жалоба может быть подана на несколько судебных актов по одному делу в одной жалобе, кроме актов по делам о несостоятельности (банкротстве)

**Раздел 2 — Порядок и сроки подачи. Принятие жалобы (п. 8–22):**

- Срок на обжалование исчисляется с даты изготовления судебного акта в полном объёме (ч. 2 ст. 176 АПК РФ), а не с даты направления копии[^1_8]
- Несвоевременное размещение акта в КАД — основание для восстановления пропущенного срока при наличии ходатайства
- Неуважительные причины: согласование с вышестоящим органом, командировка/отпуск представителя, отсутствие в штате юриста, смена руководителя и иные внутренние организационные проблемы[^1_7]
- Определение о возвращении апелляционной жалобы обжалуется в кассацию в течение 1 месяца (ч. 3 ст. 188 АПК РФ)

**Раздел 3 — Рассмотрение дела, пределы, полномочия (п. 23–45):**

- По умолчанию — коллегиальный состав из 3 судей; единолично — по жалобам на решения упрощённого производства и на определения первой инстанции (ч. 2 ст. 272, ч. 1 ст. 272.1 АПК РФ); по банкротным делам — всегда коллегиально (ч. 3 ст. 223 АПК РФ)[^1_7]
- Пределы рассмотрения — в пределах доводов жалобы и возражений; выход за пределы по собственной инициативе возможен лишь для проверки безусловных оснований отмены (ч. 4 ст. 270 АПК РФ)[^1_5]
- Новые доказательства принимаются только при обосновании невозможности их представления в 1-й инстанции; **немотивированное принятие или непринятие дополнительных доказательств может являться основанием для отмены постановления** апелляционной инстанции[^1_10][^1_5]
- Проверка соответствия выводов нижестоящих судов правовым позициям ВС РФ и ВАС РФ, изложенным в постановлениях Пленума, Президиума, обзорах судебной практики[^1_10]
- Если апелляция обнаруживает, что дело подведомственно суду общей юрисдикции, — направляет дело по подсудности

### Б. По ГПК РФ

**Постановление Пленума ВС РФ от 22.06.2021 № 16** «О применении судами норм гражданского процессуального законодательства, регламентирующих производство в суде апелляционной инстанции»  — действующее разъяснение, заменившее Постановление Пленума ВС РФ от 19.06.2012 № 13.[^1_11][^1_12]

Ключевые позиции:[^1_12][^1_11]

**Субъекты и объекты обжалования (п. 1–12):**

- Судебные приказы апелляционному обжалованию не подлежат — могут быть обжалованы только в кассацию (гл. 41 ГПК РФ)[^1_12]
- Апелляционные определения самих апелляционных инстанций не подлежат апелляционному обжалованию, поскольку вступают в силу с момента принятия
- Правом обжалования обладают стороны и иные лица, участвующие в деле (ч. 2 ст. 320 ГПК РФ); лица, не привлечённые к делу, если судебное постановление разрешило вопрос об их правах; правопреемники; Уполномоченный по правам человека и уполномоченные в субъектах — при участии в деле[^1_12]
- Государственные органы и органы МСУ, дающие заключение по делу (ст. 47 ГПК РФ), — вправе подать апелляционную жалобу вне зависимости от факта привлечения к участию в деле, если их участие предусмотрено законом[^1_12]

**Порядок и сроки подачи (п. 13–22):**

- Жалоба подаётся через суд 1-й инстанции; при подаче непосредственно в апелляционный суд — суд направляет её в суд 1-й инстанции, не возвращая заявителю (ч. 1 ст. 321 ГПК РФ)[^1_11]
- Срок — 1 месяц; исчисляется со дня, следующего за днём составления мотивированного решения[^1_12]
- По делам упрощённого производства — 15 дней[^1_3]
- Дата подачи при отправке по почте — по штемпелю на конверте или квитанции; при электронной подаче — дата поступления в информационную систему[^1_12]

**Новые доказательства (п. 40–44):**

- По общему правилу апелляция не исследует новые доказательства; допустимо — если сторона обосновала невозможность их представления в 1-й инстанции (нет вины заявителя) или суд 1-й инстанции необоснованно отклонил ходатайство об их приобщении[^1_13]
- Злоупотребление правом (намеренное сокрытие доказательств в 1-й инстанции) — основание для отказа в приобщении

**Пределы рассмотрения и полномочия (п. 45–53):**

- Рассмотрение в пределах доводов жалобы; апелляция вправе выйти за пределы доводов жалобы «в интересах законности» — при защите семьи, права на жильё, охраны здоровья, права на образование, благоприятной окружающей среды, охраны правопорядка[^1_14][^1_13]
- Если обжалуемая часть неразрывно связана с необжалуемой — апелляция проверяет решение в полном объёме
- Апелляционный суд обязан принять новое решение по делу; направление дела на новое рассмотрение в суд 1-й инстанции **по общему правилу не допускается**[^1_13]
- Несоответствие резолютивной части мотивированного решения резолютивной части, объявленной в заседании, — безусловное основание для отмены[^1_14]

## IV. СРАВНИТЕЛЬНАЯ ТАБЛИЦА: КЛЮЧЕВЫЕ ПАРАМЕТРЫ АПЕЛЛЯЦИИ В АПК И ГПК

| Параметр | АПК РФ | ГПК РФ |
| :-- | :-- | :-- |
| Нормативный источник | Глава 34, ст. 257–272.1 | Глава 39, ст. 320–335 |
| Основное Постановление Пленума | № 12 от 30.06.2020 | № 16 от 22.06.2021 |
| Срок подачи жалобы | 1 месяц (ст. 259); 10 дней — по делам об административных правонарушениях | 1 месяц (ст. 321); 15 дней — упрощённое производство; 15 дней — на определения |
| Пресекательный срок восстановления | 6 месяцев (ч. 2 ст. 259 АПК РФ) | 1 год со дня вынесения решения (ч. 2 ст. 112 ГПК РФ) |
| Суд апелляционной инстанции | Арбитражные апелляционные суды (ст. 258) | Районный суд, судебные коллегии судов субъектов РФ, апелляционные СОЮ (ст. 320.1) |
| Состав суда | Коллегиально 3 судьи; единолично — упрощённое производство и определения | Коллегиально; единолично — жалобы на решения мировых судей и упрощённое производство |
| Новые доказательства | Ограничено; при уважительных причинах или отклонении ходатайства в 1-й инстанции | Аналогично; злоупотребление — безусловный отказ |
| Пределы рассмотрения | Доводы жалобы + безусловные нарушения (ч. 4 ст. 270) | Доводы жалобы + «интересы законности» |
| Модель апелляции | Повторное рассмотрение (полная апелляция с ограничениями) | Неполная апелляция с элементами полной |
| Новое рассмотрение в 1-й инстанции | Только при безусловных нарушениях (ч. 4 ст. 270) | По общему правилу не допускается [^1_13] |
| Основания для отмены (безусловные) | Ч. 4 ст. 270 АПК РФ | Ч. 4 ст. 330 ГПК РФ |
| Форма итогового акта | Постановление (ст. 271) | Апелляционное определение (ст. 329) |

## V. БЕЗУСЛОВНЫЕ ОСНОВАНИЯ ДЛЯ ОТМЕНЫ (ч. 4 ст. 270 АПК РФ и ч. 4 ст. 330 ГПК РФ)

Перечни совпадают:[^1_16][^1_4]

- Рассмотрение дела в незаконном составе суда
- Рассмотрение дела в отсутствие кого-либо из лиц, участвующих в деле, не извещённых о времени и месте заседания
- Нарушение правил о языке судопроизводства
- Принятие судом решения о правах и обязанностях лиц, не привлечённых к участию в деле
- Решение не подписано судьёй или подписано не тем судьёй
- Отсутствие в деле протокола судебного заседания или его ненадлежащее ведение
- Нарушение тайны совещания судей
