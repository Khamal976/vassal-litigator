# study-evidence -- Исследование доказательств

Когда пользователь запускает эту команду с "$ARGUMENTS":

1. Прочитай скилл `skills/study-evidence/SKILL.md` и следуй его инструкциям.
2. Если `$ARGUMENTS` содержит указание на состав ядра (какие документы читать полнотекстно, на чём сфокусироваться) -- учти это в Фазе 1 (авто-определение ядра), не переспрашивая уже данное.
3. Если `$ARGUMENTS` содержит флаг `--refresh` -- форсируй полное перечтение ядра, игнорируя кэш по `content_hash` (см. SKILL.md → «Кэш и инвалидация»).
4. Если аргументов нет -- выполни полный pipeline из SKILL.md: Phase 0 (сверка ФС ↔ индекс) → авто-определение ядра + подтверждение Сюзереном → глубокое чтение → кросс-сверка → подъём зарытых фактов → preview → apply (каноническое досье `.vassal/analysis/evidence-dossier.md` + датированный снимок для Сюзерена + history).
