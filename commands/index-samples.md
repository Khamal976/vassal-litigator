# index-samples -- Наполнение каталога образцов

Когда пользователь запускает эту команду:

1. Прочитай скилл `skills/index-samples/SKILL.md` и следуй его инструкциям.
2. **Парсинг аргументов:**
   - Позиционные аргументы — путь(и) к корням дел (одно дело, папка-родитель для рекурсивного поиска или список).
   - Флаг `--check` — не наполнять, а **проверить каталог на битые указатели**: резолвить корень по номеру дела и проверить существование файла; несуществующие показать списком с предложением снять (молча не снимать — файл мог уехать в `Архив/`).
   - Позиционных аргументов нет — спроси Сюзерена, где лежат корни дел.
3. Выполни pipeline: сбор корней дел (лимит глубины 4, дедуп по `case_root`, два корня с одним номером — не дубль) → чтение `case.yaml` и `index.yaml` каждого дела → отбор по таблице фазы 2 → **preview** → apply → сводный итог.
4. **В каталог пишется только указатель.** Закрытый список полей — `shared/conventions.md` → «Глобальная память» → «Конфиденциальность». Ни текста документов, ни сумм, ни контрагентов, ни ФИО физлиц, ни **абсолютных путей**: только номер дела и путь относительно корня дела.
5. **Тексты документов не открывать.** Всё нужное лежит в `case.yaml` и `index.yaml`. Единственное исключение — сопоставление имён файлов в корне дела для аналитики, которой нет в индексе (позиция, карта доводов, проект решения); содержимое всё равно не читается.
6. **Не путать с `backfill-global`:** тот переносит наблюдения по судьям и оппонентам, этот — адреса документов. Если Сюзерен просит «перенести аналитику в глобальную» — это `/vassal-litigator:backfill-global`.
7. **Документы оппонентов в каталог не заводятся** — предложить `add-opponent`. Судебные акты (`решение`, `определение`, `постановление`) заводятся: они публичны и показывают, что суд принял, а что отклонил.
8. Перед записью обязательно покажи preview со сводкой по категориям и отдельной строкой — дела, где категория в карточке не заполнена (их записи не заводятся) и где пусты `applicable_norms` (матч будет грубее). По запросу «показать список» — вывести записи целиком: содержимое каталога проверяет человек.
