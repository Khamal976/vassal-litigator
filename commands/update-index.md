# update-index — Обновление индекса

Когда пользователь запускает эту команду:

1. Прочитай скилл `skills/update-index/SKILL.md` и следуй его инструкциям.
2. Проверь `.vassal/`:
   - `index.yaml` и `case.yaml` есть → обычный прогон.
   - **Нет ничего, но материалы дела в папке лежат** → это режим «индексация уже разложенного дела» (F.15), см. одноимённый раздел скилла. Покажи меню из «Предварительных условий» и **не отсылай просто в `init-case`**: прежняя редакция отправляла туда, откуда пользователь и пришёл. Нужна карточка — вызови `init-case` в режиме «только карточка» и **вернись сюда**.
   - Папка пуста, материалов нет → тогда действительно `/vassal-litigator:init-case`.
3. Выполни полный pipeline: сканирование → сравнение → preview → apply → верификация.
