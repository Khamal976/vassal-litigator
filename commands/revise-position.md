# revise-position -- Обратное распространение правок позиции

Когда пользователь запускает эту команду с "$ARGUMENTS":

1. Прочитай скилл `skills/revise-position/SKILL.md` и следуй его инструкциям.
2. Если `$ARGUMENTS` содержит саму правку (что отозвано / чем заменено / почему) -- прими её как дельту в Фазе 1, не переспрашивая уже данное. Уточняй только недостающее (напр. дана «что», но не дана «причина»).
3. Если аргументов нет -- выполни полный pipeline из SKILL.md: Phase 0 (сверка ФС ↔ индекс) → захват и классификация правки (уточняющая форма) → семантический скан служебного слоя `.vassal/` → preview затронутых артефактов → apply (запись в `.vassal/analysis/retractions.md` + опц. регенерация затронутых секций позиции + флаг index/зеркал для `update-index` + баннер в сводную позицию + history).
