# format-doc -- Оформление в .docx

Когда пользователь запускает эту команду с "$ARGUMENTS":

1. Прочитай скилл `skills/format-doc/SKILL.md` и следуй его инструкциям.
2. Если `$ARGUMENTS` указывает файл `.md` для оформления и/или тип документа (жалоба / отзыв / ходатайство / претензия) -- используй как вход Фазы 1, не переспрашивая уже данное.
3. Если файл не указан -- возьми последний подходящий подаваемый `.md` из корня дела (продукт `prepare-hearing` / `appeal` / `cassation` / `settlement`) и уточни у Сюзерена, тот ли документ оформляем.
4. Выполни pipeline из SKILL.md: Phase 0 (feature-detection python-docx; нет → fallback .md + предупреждение) → разбор `.md` по контракту → preview → детерминированный рендер через `scripts/format_doc.py` → валидация (`references/style-spec.md` §4) → сохранение (`_v2` при локе) → history.
